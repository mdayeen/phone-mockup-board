# Security Policy

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub: go to the **Security** tab of this repository and click **Report a vulnerability**.
You can expect an initial response within 7 days. Once a fix is ready, we will publish an advisory and credit you unless you prefer to stay anonymous.
